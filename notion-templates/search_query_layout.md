# Notionレイアウト: 検索クエリ週次レポート

`notion-output-pro` エージェントに渡すレイアウト仕様。DB形式・1列レイアウト（columnブロック使わない）。

## ページタイトル
`【<CLIENT_NAME>週次】検索クエリ｜YYYY/MM/DD-MM/DD`

## ページ構造（上から順に）

### 1. 冒頭：週次サマリ callout（青、📊）
```
【<CLIENT_NAME>週次サマリ】<期間>
IMP: <当週> (<前週比>) / CT: <当週> (<前週比>)
CTR: <当週>% (<前週比>pt) / CPC: ¥<当週> (<前週比>)
COST: ¥<当週> (<前週比>) / CV: <当週> (<前週比>)
CVR: <当週>% (<前週比>pt) / CPA: ¥<当週> (<前週比>)
```

### 2. 議事録参照 callout（黄、📝）
```
参照議事録: <議事録タイトル>（<日付>）
主要論点3つ:
1. <論点1>
2. <論点2>
3. <論点3>
```

Notionリンクを議事録タイトルにハイパーリンクとして貼る。

### 3. Excel Driveリンク（bookmark）
Step 7 でアップロードした viewUrl を bookmark ブロックとして埋め込む。

### 4. 論理レビュー callout（黄、⚠️）
critical-thinker 指摘＋対応 or 「指摘なし」。数値の前提・お盆補正等の注記もここ。

### 5. トグル群
- 🔽 **CV獲得TOP20**: table block、`No / 検索語句 / マッチタイプ / 広告グループ / IMP / CT / CTR / CPC / COST / CV / CVR / CPA`
- 🔽 **費用発生CV0ワースト20**: table block、`No / 検索語句 / マッチタイプ / 広告グループ / IMP / CT / CTR / CPC / COST`
- 🔽 **マッチタイプ別**: table block、`マッチタイプ / IMP / CT / COST / CV / CTR / CVR / CPA`
- 🔽 **広告グループ別**: table block、同上構造
- 🔽 **前週比較**: table block、`検索語句 / マッチタイプ / 当週CV / 前週CV / 差分 / 当週COST / 前週COST / 増減率`（TOP30に絞る）

### 6. 所感 & 推奨アクション（見出し2）
- **所感**（3-5個、bullet list）：議事録論点との紐付けを明示
- **推奨アクション**（2-3個、bullet list）：担当者・優先度・想定インパクト付き

### 7. ページ末尾：フッター（グレーcallout）
```
自動生成: <YYYY-MM-DD> (JST) | 対象: Google広告のみ
参照議事録: <議事録タイトル>（<日付>）<議事録URL>
```

## 色・アイコン規約
- 青 callout ＋ 📊: 数値サマリ
- 黄 callout ＋ 📝: 議事録参照 or レビュー指摘
- 赤 callout ＋ ⚠️: データ欠損・注意喚起
- 緑 callout ＋ ✅: 好調指標・成功事例
- グレー callout: メタ情報（自動生成、参照元）

## 禁止事項
- columnブロックを使わない（DB形式・1列レイアウト厳守）
- 断定表現（「絶対」「必ず」「業界No.1」）を使わない
- 数値は必ず単位付き（円/%/件）
- 差分は絶対値と比率（%）両方併記
